# Characters: create your own, never reuse someone else's

## The rule

Every kit needs an approved cast sheet made for THAT user. This skill contains no characters. The assistant must not supply, recall or "continue" characters from memory, earlier chats, other projects, other channels, public repositories or the examples in these files. If the environment memory holds character descriptions, ignore them unless the user states they are their own and approved for this run.

Why: shared characters make every user's videos look like one channel, confuse audiences and may infringe the original creator's identity. Original characters are what make a channel recognizable.

## Notice to show before the first storyboard (translate to the user's language)

English: "Important: create your own AI characters. This skill ships no characters and must never reuse characters from another channel, an old project or saved memory. Make a cast sheet, approve it, and only then I will build storyboards."
Vietnamese: "Lưu ý quan trọng: hãy tự tạo nhân vật AI của riêng bạn. Skill này không kèm nhân vật nào và không được dùng lại nhân vật của kênh khác, của dự án cũ hay trong bộ nhớ. Hãy tạo bảng nhân vật (cast sheet), duyệt nó, rồi mới làm storyboard."

## How to create a cast sheet

1. Ask the user for the casting brief in their own words: how many characters, adult or child, age range, ethnicity or look, build, hair, wardrobe, personality, style (live-action phone look or animation).
2. Generate 3 to 5 distinct options with the available image tool and let the user pick or adjust. Do not copy a real person's likeness; keep characters fictional adults (or clearly stylized children).
3. Build ONE approved sheet per character set: front, three-quarter and profile views, fixed wardrobe and a one-line text identity description (hair, face shape, clothing, build). Save it as the identity reference.
4. Reuse the same sheet and the same text identity description in every storyboard and prompt of that channel. Change wardrobe only if the script requires it.
5. In SPLIT mode, attach clip A's storyboard (or the sheet) as the identity reference when generating clip B.

## In prompts

Use identity phrases taken from the user's approved sheet: "[HERO]: [HAIR, FACE, WARDROBE]". Never paste identity text from this repository. Keep faces natural and slightly imperfect for live-action looks; avoid glossy artificial faces.

## Safety notes

No real, named or recognizable people. No minors in suggestive or adult contexts. Keep children, if any, safe and respectful (seated, supervised). Follow the user's platform rules.
